# Drop Box design

Live page (after GitHub Pages is enabled):
https://sjsu-cs-systems-group.github.io/DDD/dropbox/

To update the page, replace `index.html` and push to `main`.

## Enable GitHub Pages (admin, one time)

Write access cannot turn this on. After `docs/dropbox/index.html` is on `main`:

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **`main`**, folder: **`/docs`** (not `/ (root)`)
4. Save, wait a minute, then open the live URL above
